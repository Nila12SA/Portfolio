Project Overview

Aura is an iOS-inspired wellness app for meditation, breathing exercises, mood tracking, sleep support, relaxation music, and daily mental wellness insights.

02

Project Goal

Create a calming mobile experience that feels emotionally safe, simple to use, visually premium, and useful for repeated daily self-care moments.

03

Audience

Students, professionals, and wellness-focused users who need fast stress relief, sleep support, and a gentle way to understand their mood patterns.

Product Features

Wellness tools that stay simple

Daily insights

Short, supportive reflections based on mood, session history, sleep quality, and stress trends.

Recommendations

Personalized breathing, meditation, soundscape, and sleep rituals based on user goals.

Progress tracking

Streaks, calm minutes, mood improvements, and weekly wellness reports without visual overload.

Minimal navigation

Four core tabs: Home, Sessions, Insights, Profile. Each supports fast, low-friction use.
