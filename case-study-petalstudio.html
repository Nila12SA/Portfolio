Project Overview

PetalStudio is a custom bouquet builder website designed to help users create personalized flower arrangements online. The design provides a simple, elegant, and interactive shopping experience where customers can select flowers, colors, wrapping styles, and bouquet sizes based on their preferences.

02

Project Goal

The goal of PetalStudio was to design a personalized floral shopping experience that helps users confidently build and preview custom bouquets before placing an order.
